# Demo Project

Dieses neutrale Demo-Projekt zeigt, wie Projekt-Repo, AI Vault und AI-Betriebssystem zusammenarbeiten.

- `PROJECT.md` routet AI-Tools.
- `AGENTS.md` beschreibt operative Rollen und Grenzen.
- GitHub Issues sind Arbeit.
- PRs sind Lieferung.
- Review of Record entscheidet über PASS.
- Human Gate bleibt beim Menschen.
- Vault-Rückfluss hält Entscheidungen, Risiken und Lessons dauerhaft nutzbar.
