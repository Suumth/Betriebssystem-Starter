# First Installation

## Ziel

Am Ende hast du ein Projekt-Repo mit `PROJECT.md`, `AGENTS.md`, Labels, Ticket 0, PR-Template und einem leeren Vault-Projektbereich.

## Voraussetzungen

- Ein GitHub-Repo fuer operative Arbeit.
- Einen lokalen Markdown-Editor oder Obsidian fuer den Vault.
- Ein lokales AI-Tool wie Codex, Claude Code oder ein anderes Tool, das Repo-Dateien lesen kann.
- Optional: `gh`, wenn du Labels und Issues per CLI verwalten willst. Dieser Starter selbst fuehrt keine Remote-Operationen aus.

## Installation

1. Lege ein neues privates Methodenrepo oder einen lokalen Starterordner an.
2. Kopiere den Inhalt dieses Starters hinein.
3. Initialisiere Git frisch, wenn du den Starter veroeffentlichen oder weiterentwickeln willst.
4. Oeffne `ai-vault/` in Obsidian.
5. Lege dein erstes Projekt anhand von `docs/first-project.md` an.

## Reinitialisierung

Wenn in diesem Ordner bereits `.git` existiert, uebernimm diese Historie nicht ungeprueft in ein neues Repo. Erstelle fuer ein finales Starter-Repo einen frischen Git-Stand und importiere nur die neutralen Dateien.
