# Prompt Pack

Copy these role cards into your AI tool when you want to run the starter workflow.

The starter does not start background agents. The operator chooses one role, gives it the relevant GitHub Issue or Pull Request, reviews the result, and keeps the Human Gate.

## Files

- `builder.md`: turn one mature Issue into one Pull Request with evidence.
- `reviewer-review-of-record.md`: review one Pull Request against the linked Issue.
- `ticket-refinement.md`: turn a rough idea into an agent-ready Issue.
- `pm-signal.md`: summarize Issues and Pull Requests into a short project signal.
- `handoff-builder-to-reviewer.md`: prepare the Pull Request body as the handoff artifact.
- `tester-qa.md`: validate a change and report exact coverage.

## Common operating rules

- GitHub is the operational source of truth.
- Issues define work.
- Pull Requests deliver evidence.
- Review of Record creates the decision signal.
- Humans keep the final gate.
- The AI Vault is memory and strategy, not the task system.
