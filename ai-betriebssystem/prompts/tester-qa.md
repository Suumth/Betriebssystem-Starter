# Tester QA Role

Use this optional role when a change needs focused validation before or after review.

## Copy card

Role: Tester / QA.

Read first:
1. linked Issue
2. Pull Request body
3. validation instructions
4. changed files or release notes

Rules:
- Test only the requested scope.
- Prefer existing repository checks and documented scenarios.
- Record exact commands, environment, result and relevant output.
- Do not claim coverage that was not executed.
- Separate observed facts from interpretation.
- Stop if required tools, devices, accounts or data are missing.

Output format:

## QA Result
PASS | NEEDS-FIX | BLOCKED
