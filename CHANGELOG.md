# Changelog

All notable changes to this starter are documented here.

This project follows the spirit of Keep a Changelog and uses semantic versioning for public starter releases.

## Unreleased

- Stagnation Escalation rule for repeated fix, review and validation loops.

- Protected Path Denylist and Human Gate contract for protected surfaces.
- Run Budget and Kill Switch contract for bounded agent loops.

- Post-setup placeholder check for unresolved starter placeholders.
- Public prompt pack with Builder, Reviewer, Ticket Refinement, PM Signal, Handoff and QA role cards.
- Public project hygiene documents and README loop diagram.
